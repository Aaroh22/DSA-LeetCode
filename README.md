# DSA & LeetCode Solutions

A collection of my **Data Structures and Algorithms (DSA)** solutions, primarily written in **C++**, as part of my continuous problem-solving and technical interview preparation.

This repository documents my progress on LeetCode while helping me strengthen my understanding of algorithms, data structures, and efficient problem-solving techniques.

*The repository will continue to grow as I practise new topics and patterns.*

## Repository Structure

Solutions are automatically uploaded using **LeetHub** after successful LeetCode submissions.

Each problem is stored in its own directory, identified by its LeetCode problem number and title.

Example:

```text

```

## My Approach

While solving problems, I focus on:

1. Understanding the problem and identifying its underlying pattern.

3. Improving time and space complexity wherever possible.
4. Learning from mistakes and revisiting challenging problems.
5. Building consistency through regular practice.
